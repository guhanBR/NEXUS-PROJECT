Optimization Engine Mechanics

When a disruption is triggered, RebalanceX executes a Mixed-Integer multi-factor constraint optimizer:

1. Hard Constraint Verification

Ensures all reassigned tasks match minimum required skill levels, respects prerequisite DAG dependency chains, and prevents assignment to unavailable staff.

2. Multi-Objective Minimization

Minimizes schedule makespan delay, prevents individual engineer overload, and reduces unnecessary churn from the original plan.

3. Auditable Explainability

Synthesizes explicit reasons for each reallocation, allowing engineering leadership to inspect evidence before approving.
